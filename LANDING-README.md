# Anteprima landing - 115° anniversario

Landing page statica per la campagna anniversario di Premiato Mobilificio.

## Anteprima locale

Apri un terminale nella cartella del repository e avvia un server statico su `127.0.0.1:4173`, poi visita `http://localhost:4173`.

## File principali

- `index.html`: sezioni, copy e modulo di richiesta.
- `styles.css`: layout responsive ispirato alle brand guidelines e alle grafiche fornite.
- `script.js`: prepara una email indirizzata a info@premiatomobilificio.it; il browser non invia automaticamente i dati.
- `assets/campaign/`: immagini di riferimento fornite per la campagna.

## Prima della pubblicazione

Il copy fornito indica sconto del 50%, quattro elettrodomestici, otto progettazioni e scadenza a novembre 2026. Verificare condizioni, disponibilita, modelli, periodo e informative aggiornate prima di usare la pagina come campagna attiva. Il modulo usa `mailto` e non e collegato a un sistema CRM o di raccolta contatti.
